# Public source launch

The repository was made public on October 3, 2026. This is a source publication
with a recorded replay. Native distribution and new physical acceptance remain
separate decisions.

## Prepared in this repository

- Separate locomotion and harness entry points, with the same prominence.
- A [browser replay](https://Slagathore.github.io/LoColemotion/) from three retained
  development sessions, with local playback for offline use.
- A small receipt set, evidence index and local integrity verifier.
- Setup instructions that separate the portable core, playback and native Studio.
- License FAQ, commercial inquiry route, citation metadata and issue/PR templates.
- [An explanation of the harness](WHY_THE_HARNESS_EXISTS.md) with actual invalid,
  negative and accepted records.

## Owner decisions

| Decision | Recommended next step | Tradeoff |
| --- | --- | --- |
| Repository visibility | Public source publication completed October 3, 2026 | People can inspect and cite it. Visibility is not native binary redistribution permission. |
| Harness and non-SDK licensing | Keep the current terms until you decide whether to extend them or issue separate harness terms | Existing scope preserves your options, but users cannot assume the complete harness, replay or root docs have the SDK's reuse permissions. |
| Evidence hosting | Publish a small, versioned proof pack with checksums before offering the full archive | Lower storage and onboarding cost; deeper independent audits still need the missing dependency closure and original source history. |
| Commercial contact | Choose a public business address or contact page | A GitHub issue works for a first non-confidential inquiry; a dedicated route is better for actual negotiations. |
| Native distribution | Define and qualify a relocatable runtime/evidence package | More engineering and third-party license work, but much easier live adoption. The retained candidate packages are not release artifacts. |
| Citation archive | Choose an archival host and mint a DOI for an intentional version | Stable academic citation; requires a deliberate archive and version. No DOI or release tag is invented here. |

## Assets worth making next

1. A short locomotion clip with the engine, body, campaign and observation scope
   visible. Do not splice unlike sessions into a performance comparison.
2. A harness clip following one actual refusal, retained failure and qualified
   successor. Use the real receipts; do not stage a new “official” experiment.
3. A stranger's first-use report from the hosted replay and the public setup
   instructions. Use the report to choose the next onboarding improvement.
4. A technical write-up from the existing actuator and force-sampling comparison.

The main launch story has two parts: portable control through real native
physics, and experimental infrastructure that can defend the result. Keep both
visible in the README, demo and announcement.
