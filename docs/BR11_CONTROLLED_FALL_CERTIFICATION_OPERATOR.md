# BR11 Controlled-Fall Certification Operator

## Purpose

This document defines the only supported BR11 certification run for the exact
scaffold-constrained planar protective-fall claim. It does not accept the
milestone, admit knowledge, authorize creature repair or guidance, predict
injury, or generalize fall arrest.

The fixed campaign is:

```text
data/lab/campaigns/BR11_controlled_fall_promotion_campaign_v1.json
```

## Program scopes

`BR11.0` certifies the strict semantic protective/core contact registry and
pure finite controller. Authored roles do not invent contact; self or creature
contact cannot masquerade as ground contact; the controller requests no
torque outside `FALL_ARREST`; and the controller has no repair or guidance
authority.

`BR11.1` certifies supervisor authority only. `FALL_ARREST` requires
infeasible upright recovery, imminent impact, and protective capacity.
`FALLEN` requires the declared stable-observation dwell. The supervisor itself
applies no force or torque and grants no guidance authority.

`BR11.2` certifies the paired mechanics oracle only. Whole-system kinetic
energy and linear momentum, centroidal angular momentum, reconstructed
external impulse, explicit mechanical-energy accounting, core approach speed,
and the local core-load witness retain their exact declared semantics. The
kinetic proxy is not an injury model; the local witness is not generalized
load allocation.

`BR11.3` certifies the paired live Godot/Jolt result only. One exact planar
two-body scaffold and one finite paired hinge deploy the semantic protective
link before core impact in the active world. The active world improves all
preregistered comparisons against the same-state zero-command control. Both
worlds end stably `FALLEN`, not upright.

`BR11.4` is integrity-only. It can reject digest mutation, hidden authority,
missing mechanics channels, false injury/allocation semantics, assistance,
identity substitution, unstable terminal state, or claim broadening. It
cannot substitute for a physical milestone program.

## Run command

From PowerShell in the repository root:

```powershell
& .\scripts\run_br11_controlled_fall_certification.ps1
```

The operator:

1. requires PowerShell 7.5 or newer;
2. requires the fixed Godot 4.7 executable and SHA-256;
3. requires a clean committed source tree;
4. verifies the pinned BR1 inventory is unchanged;
5. builds the exact declared byte inventory;
6. runs ten fresh contained Godot target processes;
7. retains raw engine logs, transcripts, reports, metrics, capsules,
   manifests, checksums, and bundle receipts;
8. reconciles both replicates of every program;
9. performs a complete independent readback;
10. writes the BR11 certification report; and
11. creates and verifies a detached BR11 report-domain receipt.

Preflight without physics:

```powershell
& .\scripts\run_br11_controlled_fall_certification.ps1 -PreflightOnly
```

Preflight is explicitly non-promotable.

## After certification

Certification alone leaves BR11 unaccepted. The next allowed operation is a
source- and receipt-pinned milestone decision review. Knowledge admission, if
later authorized, is a separate append-only operation and must remain
observation-only unless a future validated consumer, transfer campaign, and
separate guidance decision exist.
