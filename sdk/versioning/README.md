# SporeSpore SDK versioning and compatibility

This directory is the public compatibility boundary for SDK `0.1.0`. It makes
the version number, C ABI, JSON schema evolution, migrations, and deprecations
machine-readable and testable. It does not authorize release or claim that a
physics engine walks.

The authoritative files are:

- [`compatibility_policy_v1.json`](compatibility_policy_v1.json): release,
  ABI, schema, migration, and deprecation rules;
- [`c_abi_manifest_v1.json`](c_abi_manifest_v1.json): all 41 live public C symbols,
  their signature classes, stable status discriminants, and lifecycle status;
- [`schema_registry_v1.json`](schema_registry_v1.json): strict public input
  schemas and the only automatic cross-schema migration currently allowed;
- [`deprecation_registry_v1.json`](deprecation_registry_v1.json): deprecated
  symbols/schemas, replacements, migration requirements, and earliest removal
  versions, including Python methods that emit `DeprecationWarning`; and
- [`migrations.py`](migrations.py): the fail-closed migration engine.

The clean pushed-source V0-V6 evidence is indexed by
[`versioning_validation_manifest.json`](versioning_validation_manifest.json).
It now certifies exact commit `211cb78c1db6818c44470714a165db0df8dbd2dd`,
including the additive `ss_resolve_adaptation_v1_json` surface: all 27 declared
C symbols resolved, all 35 schemas were registered, all 20 public ABI input
schemas were covered, and V0-V6 passed with zero worlds. The retained report is
`SporeSpore_Evidence/sdk-versioning-211cb78/report.json`, SHA-256
`875e16efe7feb7c18283231d9f096c39d67cd72c9a7c003770acd0efd1a7ef09`.
Historical reports remain unchanged.

The live registry now contains `58` schemas and the live ABI contains `41`
symbols. Additive surfaces since the retained QSDK-R18 report include online

## Compatibility promise

The SDK uses Semantic Versioning `MAJOR.MINOR.PATCH`, but `0.x` remains a
public preview. Patch releases may not remove or change active C ABI symbols,
change status discriminants, or change a schema's meaning in place. A
pre-1.0 minor release may remove a preview surface only after the registry's
notice window, and a C ABI removal also requires a new ABI generation.

ABI generation 1 exposes only C scalars, caller-owned buffers, and UTF-8 JSON;
no Rust layout crosses the boundary. JSON records are stricter than ordinary
“best effort” configuration: an unknown schema, unknown field, missing field,
nonfinite number, or unregistered migration fails closed.

Schema IDs are immutable semantic identities. A changed record shape or
meaning receives a new schema ID. Multiple versions may coexist, which is why
the v1/v2/v3 stability functions remain separately callable. The migration
engine never guesses how to translate between them.

## Real registered migration

The one automatic migration in `0.1.0` converts
`sporespore_balanced_wave_step_request_v1` into
`sporespore_balanced_wave_policy_step_request_v1`. It injects the explicit
policy ID `sporespore_balanced_wave_v1`, because the unnamed legacy ABI is
frozen to BW2-A. It deliberately does **not** substitute the selected BW5R-B
policy. Conformance executes both old and migrated requests through the real
dynamic library and requires byte-equivalent decoded controller output.

From PowerShell at the repository root:

```powershell
$env:SPORESPORE_LOCOMOTION_LIBRARY = (
  Resolve-Path .\sdk\target\release\sporespore_locomotion_core.dll
).Path

python -m sdk.versioning.migrations `
  --input .\legacy-request.json `
  --target-schema sporespore_balanced_wave_policy_step_request_v1 `
  --output .\migration.json
```

The output filename must be exactly `migration.json`, and an existing output
is never overwritten. The receipt includes canonical source and target
SHA-256 values generated by the portable core.

## Run conformance

From PowerShell at the repository root:

```powershell
.\sdk\run_versioning_conformance.ps1
```

The runner builds the real release library, runs the source tests, resolves
all declared C symbols from that library, verifies version lockstep, executes
the registered migration, tests negative migration paths, and compiles V0-V6.
It opens zero physics worlds.

To retain clean pushed-source evidence, use a new durable path:

```powershell
.\sdk\run_versioning_conformance.ps1 `
  -Output C:\Users\Cole\CodeStuff\games\SporeSpore_Evidence\sdk-versioning-<commit>\report.json
```

Passing this gate proves only that versioning, ABI, migration, and deprecation
contracts are public and executable. Packaging, publication, engine C6,
walking, physical acceptance, and completed-engine-neutral-SDK authority all
remain separate gates.
